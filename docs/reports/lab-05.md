# ЛР5. Форма и список в памяти

| Проверка | Что делаю | Факт |
|---|---|---|
| Успех | тема «Защита проекта», auditoriumId = 2, описание «Бронирование аудитории» | переход на /, строка TMP-3 со статусом New появилась |
| Отказ | тема «abc» | под полем «Тема» ошибка «Тема: от 5 до 80 символов», строка не добавлена |
| Память | F5 после успешного создания | добавленная строка исчезла (ожидаемо: сервера и БД пока нет) |

Тип auditoriumId: number (поле с v-model.number).
Массив записей находится в одном модуле: frontend/src/ticketsStore.js.
